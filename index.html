灯環のレゾナンス

更新日: 2026年9月6日

はじめの灯を、ともすところから。起動の土台と、仲間に指示して戦うルールを確認しました。

最初の目標は、小さな戦闘を最後まで遊べること。現在は画面につなぐ前の段階です。このページでは、できたことと、これから確かめることをお届けします。

試遊と素材

試遊と素材は準備中

前回からの変化

  • 基本ウィンドウの起動を確認し、1人と4人の編成で勝利まで進む戦闘ルールを用意しました。まだ画面から操作する試遊版ではありません。
  • 初回の開発記録を掲載しました。試遊と素材プレビューは、準備と確認が整い次第ここへ追加します。

完成した内容

  • Windowsで基本ウィンドウを開き、閉じて終了するところまで確認しました。
  • 個別コマンド・作戦・支援・勝敗判定・再挑戦の戦闘ルールを、画面を使わない検証で確認しました。

残作業

  • 日本語の戦闘画面をつなぎ、選択から勝敗・再挑戦まで実際に操作できるようにすること。
  • キャラクターと戦闘背景のドット絵、音楽・効果音の制作と再生確認。
  • ブラウザで遊べる形への変換と、試遊・素材プレビューの公開。探索や育成は、その先の段階です。

問題点

  • 現時点では遊べる試遊版がありません。基本ウィンドウの表示と、戦闘ルールの検証までです。
  • 操作の分かりやすさ、画面の見やすさ、音量、ブラウザでの動作は、これから確認します。

起動・操作・再生方法

  • このページでは進捗を読めます。試遊と画像・音のプレビューは準備中のため、まだ開いたり再生したりできません。
  • 開発用ファイルを持つ方向け：プロジェクトのフォルダーで「uv sync --locked」、続けて「uv run python main.py」を実行すると、基本ウィンドウが開きます。終了はウィンドウを閉じます。
  • 戦闘の操作方法は、操作画面を確認した後に掲載します。

確認したこと

  • Windowsで基本ウィンドウの表示と、閉じた後の正常終了を確認しました。
  • 画面を使わず、1人・4人の編成で勝利まで進行することと、同じ条件・操作で同じ結果になることを確認しました。

未実施の確認

  • 実際の画面での戦闘操作、画像の表示、音楽・効果音の再生。
  • ブラウザ版の起動・主要操作と、公開先での試遊・素材表示。

次の約3時間の成果

  • 次の約3時間では、戦闘画面と素材の接続を進め、コマンド選択から勝敗までを操作して確かめられる状態を目指します。
  • 確認できた範囲に合わせて、操作案内と試遊・プレビューの準備状況を更新します。
