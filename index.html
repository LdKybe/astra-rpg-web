命令・作戦・支援で勝敗まで進むルールと、同じ戦闘を再現して確認する仕組みができました。

開始時の魔法少女は1人、戦闘パーティは最大4人。主人公モルは枠外から仲間を支えます。最初の約3時間では戦闘の土台と素材を進めましたが、まだ画面から遊べる段階には届いていません。

前回からの変化

  • 初回掲載から、1人・4人の勝利、敗北、先行した回復を見て行動を選ぶ作戦を含む戦闘を、保存した操作列から再現できるようになりました。
  • モル、魔法少女4人、敵3体、夜の遺跡背景と、戦闘BGM・6種類の効果音の制作が進みました。画像の表示と音の再生動作は確認済みで、聞き分け確認と画面への接続が残っています。
  • 進捗ページを先行公開し、実際の公開先で日本語表示とキーボード操作を確認しました。

完成した内容

  • Windowsで基本ウィンドウを開き、閉じて正常に終了する起動基盤。
  • 個別の攻撃・スキル・防御、行動時に最新の戦況を読む作戦、モルの回復支援、勝敗判定と再挑戦の戦闘ルール。画面を使わず検証しました。
  • 同じ初期条件・乱数の種・操作列から、戦況・行動履歴・勝敗をJSONで再現して照合する機能。
  • 現在地と履歴を読める進捗ページと、その初回の公開確認。

残作業

  • BGMと選択・決定・攻撃・回復・勝利・敗北の効果音を、人が聴いて区別できることの確認。
  • 日本語の戦闘画面へルールと素材をつなぎ、命令・作戦・支援から勝敗・再挑戦まで実際に操作できるようにすること。
  • ローカルでの実操作を確認した後、ブラウザ向けの変換・起動・操作・画像・音を検証し、試遊と素材プレビューを公開すること。
  • その先に、報酬・勧誘・装備・育成・広いマップ探索・保存を接続します。本編とクリア後の内容、プレイ時間の実測も後続です。

問題点

  • まだ遊べる戦闘画面やWeb試遊はありません。操作の分かりやすさと戦闘画面の見やすさは未確認です。
  • 音の再生進行・終了・音量変更・消音は技術確認済みですが、BGMの聴取と効果音の聞き分けは確認待ちです。素材を完成扱いにはしていません。

起動・操作・再生方法

  • このページで進捗と履歴を閲覧できます。公開ページ上の試遊・画像・音プレビューは準備中です。
  • 開発用ファイルを持つ方向け：プロジェクトのフォルダーで「uv sync --locked」、続けて「uv run python main.py」を実行すると基本ウィンドウが開きます。終了はウィンドウを閉じます。
  • 画面なしの1人戦闘は「uv run python main.py --headless tests/scenarios/solo-victory.json」、4人の検証は「uv run python main.py --headless tests/scenarios/squad-victory.json」で実行できます。結果はJSONに出力されます。
  • 画面での戦闘操作と、このページでの素材再生の手順は、提供できる状態を確認してから掲載します。

確認したこと

  • 戦闘・再現・素材・公開ページを含む自動検証86件を独立した確認で通過しました。テストの成功を、ゲーム全体の完成とは扱っていません。
  • 4種類の再現シナリオを各2回実行し、同じ戦況・履歴・勝敗になることを確認しました。
  • 全9画像と日本語を実際に表示しました。BGM・6効果音の実再生、ループ、音量・消音など27項目の再生動作を確認しました。聴感の確認は別に残っています。
  • 進捗ページの初回公開で、4配布ファイルの応答と内容の一致、日本語表示、幅360pxでの収まり、Tab・Enter操作を確認しました。

未実施の確認

  • BGMの聴取と、6種類の効果音の人による聞き分け。
  • 実際の戦闘画面での操作と、ゲーム内での画像・音の統合。
  • ブラウザ版ゲームの起動・主要操作と、公開先での試遊・制作素材の表示・再生。

次の約3時間の成果

  • 次の約3時間では、素材の聴感確認を終えたうえで、日本語の戦闘画面を接続し、1人開始から命令・作戦・支援・勝敗・再挑戦までを操作できる成果を目指します。
  • 4人編成の表示と操作も確かめ、ローカルで成立した範囲をWebへ変換して、ブラウザでの起動・入力・画像・音の確認へ進みます。
  • 確認できた成果を試遊・素材プレビューへつなぎ、次のチェックポイントで増えた遊びと残る問題を更新します。
